# 🧪 A/B Testing — Online Store Analysis

## 📌 Descripción del proyecto

Análisis de datos realizado para una tienda online con el objetivo de evaluar hipótesis de negocio y analizar los resultados de un experimento A/B.

El proyecto combina priorización de hipótesis, análisis de ingresos, comportamiento de compra, conversión y pruebas estadísticas para apoyar la toma de decisiones basada en datos.

## 🎯 Objetivo

Analizar el comportamiento de los usuarios de los grupos A y B para determinar si existen diferencias estadísticamente significativas y evaluar el impacto del experimento sobre las principales métricas del negocio.

## 🛠️ Herramientas utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- SciPy
- Jupyter Notebook
- Análisis estadístico
- A/B Testing

## 🔎 Proceso de análisis

1. Exploración y preparación de los datos.
2. Priorización de hipótesis mediante los frameworks ICE y RICE.
3. Análisis de ingresos acumulados por grupo.
4. Análisis del tamaño promedio de los pedidos.
5. Evaluación de la tasa de conversión.
6. Identificación de valores atípicos.
7. Comparación de los grupos A y B.
8. Aplicación de pruebas de significancia estadística.
9. Análisis de resultados con datos sin filtrar y datos filtrados.
10. Elaboración de conclusiones para la toma de decisiones.

## 📊 Análisis realizado

Durante el proyecto se evaluaron métricas relacionadas con:

- Ingresos acumulados
- Número de pedidos
- Tamaño promedio de compra
- Conversión
- Comportamiento de los grupos A y B
- Valores atípicos
- Significancia estadística

## 💡 Enfoque de negocio

El análisis permite transformar los resultados de un experimento A/B en información útil para la toma de decisiones, evaluando si los cambios observados entre los grupos representan diferencias estadísticamente significativas.
